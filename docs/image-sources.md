## Display policy

- Use documentary photographs below the interactive line heroes, not inside them.
- Preserve each photograph’s native proportions and crop only inside declared aspect-ratio frames.
- Use the `position` value in `data/photography.ts` to retain the subject at desktop and mobile widths.
- Use neutral overlays only; do not apply monochrome, blue, green, or branded colour filters.
- If an image is replaced, update this register and `data/photography.ts` in the same commit.
